# Contributing to testcmp

Thanks for your interest in contributing!

## Getting started

1. Fork and clone the repository.
2. Run `go test ./...` to make sure everything passes.
3. Create a feature branch from `main`.

## Making changes

- Keep changes focused. One feature or fix per PR.
- Add tests for new functionality.
- Run `go vet ./...` before submitting.
- Follow existing code style and conventions.

## Pull requests

- Open a PR against `main`.
- Include a clear description of what the change does and why.
- Make sure CI passes (tests, vet, staticcheck).

## Reporting issues

- Use GitHub Issues.
- Include a minimal reproduction if possible.
- Describe the expected vs actual behavior.
